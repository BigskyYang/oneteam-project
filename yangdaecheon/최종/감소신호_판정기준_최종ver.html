관계 약화를 잡는 기준과 약화 이후를 보는 방법

10~13단계 검증으로 바뀐 정의 전체. 팀원이 같은 기준으로 계산할 수 있도록 정리했다.

작성 양대천 · 2026.09.28 개정 근거 output/10 ~ 15 단계 산출물개정 2026.09.29 (회복 판정 폐기 · 단기 반등은 참고용)
분석 대상은 5,941개 법인의 관계 약화 8,176건이다.
  • 단위가 법인이 아니라 '감소 에피소드'로 바뀌었다. 한 법인이 여러 번 약화될 수 있고, 매번 결과가 다르기 때문이다.
  • 기준은 작년 같은 3개월 대비 입금 40% 이상 감소다(예전 30%).
  • '회복' 판정은 쓰지 않는다. 판정 시점(t+1~t+3 ~ t+4~t+6)과 기준(60~90%)을 바꿔 봐도, 몇 달 안의 반등은 6개월~1년 뒤 상태를 거의 맞히지 못했다. 약화 직후 3개월의 반등은 단기 반등(참고용)으로만 남기고, 약화 이후는 7~12개월 뒤 입금 수준(평소 대비 %)으로 본다.
  • 상품 격차는 기획서 RQ3처럼 같은 유형 안에서 약화 고객 vs 약화되지 않은 고객으로 비교한다.
  • 예전 숫자(5,997 / 2,700 / 2,959 / 338, 8,335 코호트)는 폐기된 정의의 수치다. 쓰지 않는다.

01한눈에 보는 판정 흐름

한 법인을 기준월 t에서 본다. 올해 최근 3개월을 작년 같은 3개월과 비교해 약화를 잡고, 바로 다음 3개월을 다시 그 달의 작년과 비교해 단기 반등을 참고로 기록한다. 두 비교 모두 같은 달끼리 비교하므로 계절 영향이 빠진다. 약화 이후의 주 잣대는 그림 밖, 7~12개월 뒤 입금 수준이다.

03약화 이후를 보는 방법

구분정의쓰임
7~12개월 뒤 입금 수준 (Y) 주 잣대Y = 계절조정 입금 t+7~t+12 평균 ÷ 계절조정 before(t−14~t−12) 평균. 계절조정 = 월 입금 ÷ 그 달 업종의 2023년 계절지수. 6개월 중 4개월 이상 관측된 달만 평균. 기준선을 긋지 않고 %를 그대로 쓴다대응군별 "방치하면 어떻게 되나"(예후). 16단계 산출 완료: 72% / 61% / 44% / 37%, 비교군 102%. 2024.03~12 약화(5,537건)만 계산 가능
Y 민감도① 6개월 모두 관측된 경우만 ② Y24 = 원값 t+7~t+12 평균 ÷ 원값 t−17~t−12 평균(24개월 전 같은 달, 계절조정 없음)둘 다 대응군 순서가 같았다. Y24는 전체적으로 7~17%p 높게 나온다(2년 추세가 섞임)
관측중단마지막 관측 달이 t~t+3 이고 데이터 끝(2025.12)까지 다시 나타나지 않음따로 센다. '이탈'이라 부르지 않는다
단기 반등 참고반등 창(t+1~t+3) 평균이 같은 달 작년(t−11~t−9) 평균의 70% 이상설명용. 고객 구분이나 비교 기준에는 쓰지 않는다
반등 없음 참고반등 창이 유효한데 70% 미만설명용
판정불가반등 창 또는 비교 창이 무효 (3개월 중 관측 2개월 미만)반등 집계에서만 제외
왜 '회복' 판정을 버렸나. 판정 방식(한 번 도달 / 종점 / 계속 유지), 시점(t+1~t+3 ~ t+4~t+6), 기준(60~90%)을 모두 바꿔 봤지만(13·14단계), 어느 조합도 6개월~1년 뒤 상태를 잘 맞히지 못했다(평가 점수 0.1대, 0이 우연·1이 완벽). 예를 들어 단기 반등 사건 중 6개월 뒤에도 평소의 70% 이상인 비율은 36.9%, 반등 없음은 25.5%다. 게다가 반등 여부는 약화 3개월 뒤에야 알 수 있어 조기 대응에 쓸 수 없다. 그래서 고객 구분은 약화가 잡힌 순간 보이는 것으로만 한다.
약화 시점에 보이는 구분 (고객 구분·상품 제안에 쓰는 축)
· 입출금 방식(15단계): 같은 창에서 요구불출금도 40% 이상 줄면 동반 감소형(약 2/3), 아니면 출금 유지형(약 1/3). 단기 반등 비율이 48.7% vs 63.3%로 크게 달랐고, 16단계에서 7~12개월 뒤 수준으로도 차이가 유지됨을 확인했다(중앙값 차이 26%p, 23~30%p).
· 강한 약화: 같은 창에서 요구불예금잔액 40% 이상 감소, 또는 이용채널수 3개월 평균 1개 이상 감소, 또는 자동이체 _ord 1 이상 감소
· 대응군 = 입출금 방식 × 강한 약화 = 4개 (출금 유지·약화 1,320 / 출금 유지·강한 1,397 / 동반·약화 2,084 / 동반·강한 3,370건)
· 변동성: 입금이 원래 들쭉날쭉한 고객(4·5분위)은 결과를 따로 표시

05이 기준으로 계산했는데 숫자가 다르면

  • 에피소드가 아니라 법인 첫 신호만 셌다
    8,176은 에피소드 수, 5,941은 법인 수다.
  • 빈 달을 "3개월 모두 관측"으로 걸었다
    exclude 로 하면 에피소드 7,131 / 법인 5,198 이 나온다. 기본은 partial.
  • 빈 달을 0으로 채웠다
    빈 달은 NaN(모름)이다. 0 은 "거래가 없었다"는 뜻이라 가짜 감소가 생긴다.
  • 금액을 float32로 읽었거나 경계를 포함하지 않았다
    정확히 40% 감소인 경우가 흔하다.
  • 단기 반등을 before 와 비교했다
    반등 창(t+1~t+3)은 그 달의 작년(t−11~t−9)과 비교한다. t+4~t+6(옛 시점)으로 계산하면 3,941 / 3,084가 나온다. 어느 쪽이든 참고용이다.
  • 36개월 연속 관측 법인만 봤다
    36개월 모두 관측된 법인은 3,372개(21.8%)뿐이고 큰 법인에 치우쳐 있다.

06코드로 옮기면

원본 구현: code/eda_signal_definition.py(Detector, episodes), code/eda_channel_and_type.py(단기 반등 기준치·입출금 유형), code/eda_response_design.py(adjusted_demand, prognosis_values, 금융 이용 유형), code/panel_cache.py(공통 캐시). 새로 짜지 말고 가져다 쓴다.

# pres   : (법인수, 36) bool  — 그 달 행이 있으면 True
# demand : (법인수, 36) float64 — 요구불입금금액, 행이 없는 달은 NaN (0 아님)
# 월 인덱스 0 = 2023.01, 35 = 2025.12
EPS = 1e-9

def window_mean(c_rows, lo, hi):
    """lo~hi-1 구간. 3개월 중 2개월 이상 관측이면 관측 달 평균, 아니면 NaN"""
    ok = pres[c_rows, lo:hi].sum(axis=1) >= 2
    return np.where(ok, np.nanmean(demand[c_rows, lo:hi], axis=1), np.nan)

# 1) 신호 달
signal = {}
for t in range(14, 30):                                   # 2024.03 ~ 2025.06
    before = window_mean(ALL, t - 14, t - 11)
    after  = window_mean(ALL, t - 2,  t + 1)
    rate   = (before - after) / before
    signal[t] = np.isfinite(rate) & (before >= 10 - EPS) & (rate >= 0.40 - EPS)

# 2) 에피소드: 법인별 신호 달을 정렬해 간격 2개월 이하는 한 묶음, 첫 달이 판정 t

# 3) 약화 이후 (에피소드 첫 달 t 기준)
def after_signal(c, t):
    if t <= last_pos[c] <= t + 3:                         # 끝까지 복귀 없음
        return "관측중단"
    now  = window_mean([c], t + 1, t + 4)[0]              # t+1 ~ t+3
    base = window_mean([c], t - 11, t - 8)[0]             # 같은 달 작년 (t-11 ~ t-9)
    if not (np.isfinite(now) and np.isfinite(base)) or base <= 0:
        return "판정불가"
    return "단기 반등" if now >= (0.70 - EPS) * base else "반등 없음"   # 참고용

# 4) 주 잣대: 7~12개월 뒤 입금 수준 Y (16단계, 2024.03~12 약화만: t <= 23)
#    adj[c, m] = demand[c, m] / 계절지수2023[업종(c, m)][m % 12]   (행 없는 달은 NaN)
def prognosis_y(c, t, min_obs=4):
    fut  = adj[c, t + 7:t + 13]                           # t+7 ~ t+12, 6개월
    base = adj[c, t - 14:t - 11]                          # before 창 그대로 (분모 고정)
    if np.isfinite(fut).sum() < min_obs or np.isfinite(base).sum() < 2:
        return np.nan                                     # 관측중단·미래 부족은 0으로 채우지 않고 따로 센다
    return np.nanmean(fut) / np.nanmean(base)
의사코드는 이해를 돕기 위한 요약이다. 실제 수치는 위 스크립트의 함수로 재현한다. 통계 비교는 에피소드 단위로 하고, 신뢰구간은 법인 단위로 재표집한다(같은 법인의 에피소드는 서로 독립이 아니다).

07함께 지킬 것

  • 금액 비교는 중앙값으로 한다.
  • 상품 보유는 금액이 아니라 좌수 순서코드(_ord) > 0으로 판정한다.
