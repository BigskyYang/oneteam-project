# 양대천 작업 폴더

> 2026-10-06 최종 정리. 팀의 최종 주제는 **거래 건수 기반 법인고객 위축 신호 탐지**이고, 그 분석 코드·노트북은 [건수분석/](건수분석/)에 있다.
> `최종/`·`전처리_가이드/`는 그 전 단계(요구불입금 기반 탐지, 2026-09-29까지)의 기록이다. 모든 수치는 법인 집계값이다.

## 맡은 일

- 분석 기획과 위축 지표 설계
- 거래 건수 기반 분석 전체(계획 P1~P10, 노트북 01~09, 보고서형 노트북)
- 최종 발표 6~8장: 신호 검증, 고객별 비교, 민감도 분석

## 거래 건수 기반 분석 (최종)

**핵심 한 줄**: 거래 건수가 직전 6개월 대비 35% 이상 줄어든 법인은 이후 6개월 요구불입금액이 크게 약화될 가능성이 같은 조건의 비교 법인의 약 4.7배(RR 4.69, 95% 신뢰구간 3.75~5.95)였고, 독립 표본(RR 4.29)과 20가지 분석 조건에서도 같은 방향이었다. 약화를 직전 6·12개월 대비로 다시 정의해도 같은 방향이지만 크기는 1.9~3.5배로 작아진다(4.7배는 '작년 같은 달 대비 약화' 정의의 값). 인과나 조기경보가 아닌 '함께 나타나는 신호'이며, 약화의 일부만 포착하는 선별 도구다.

제출용 결과 보고서, 상세 결과 HTML, 발표 슬라이드(6~8장 포함)는 집계 수치를 담은 문서라 팀의 데이터 반출 검토 없이는 이 레포에 올리지 않았다(`건수분석/.gitignore`).

당시 결론 (요약)

- **탐지**: 작년 같은 3개월 대비 요구불입금 40% 이상 감소. 에피소드 8,176건 / 법인 5,941개. 6개월 뒤 감소 유지 39.9% vs 비교군 18.2%.
- **업무량**: 월 약 440개 법인 (대구 211·경북 166·수도권 58·부울경 51), 재탐지 25%.
- **예후**: 1년 뒤 평소 대비 72% / 61% / 44% / 37% (출금유지·약화 / 출금유지·강한 / 동반·약화 / 동반·강한), 비교군 102%.
- **대응**: 보정 후 상담 후보 상품 없음. 약화 고객은 1년 전부터 채널·전담·등급으로 본 관계가 얇았다.
