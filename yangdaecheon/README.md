**핵심 한 줄**: 거래 건수가 직전 6개월 대비 35% 이상 줄어든 법인은 이후 6개월 요구불입금액이 크게 약화될 가능성이 같은 조건의 비교 법인의 약 4.7배(RR 4.69, 95% 신뢰구간 3.75~5.95)였고, 독립 표본(RR 4.29)과 20가지 분석 조건에서도 같은 방향이었음. 약화를 직전 6·12개월 대비로 다시 정의해도 같은 방향이지만 크기는 1.9~3.5배로 작아짐(4.7배는 '전년 같은 달 대비 약화' 정의의 값). 인과나 조기경보가 아닌 '함께 나타나는 신호'이며 약화의 일부만 포착하는 선별 도구임.
