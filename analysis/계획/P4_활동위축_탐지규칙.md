# P4. 활동 위축 탐지 규칙 설계 (계절성 · 비교 기준 · 창 길이 · 활동량 하한)

> 이전: [P3](P3_채널구조탐색.md) · 다음: [P5](P5_위축기준과_입금검증.md)

## 1. 목적과 질문
국내 5채널 **총 활동량 I1** 의 변화율로 위축을 탐지하는 규칙을 정한다. 기존 입금 기반 파이프라인(④)과 **같은 절차**를 지수만 바꿔 적용하며, 입금은 이 단계에서 쓰지 않는다 (P5의 검증이 순환이 되지 않도록).

## 2. 지수 (P2에서 확정된 것을 사용)
- **주 지수 I1** = 국내 5채널 근사 건수 합 (cap 60). 사전 고정이며 결과를 보고 바꾸지 않는다.
- **민감도**: I1(cap 51 / 100), 구간 하한 지수 I1_low, **상한 시나리오** I1_high(50건초과=100, 실제 상한 아님), I2 = 순서 코드 합, I3 = 사용 채널 수. P7에서 결론이 같은지 본다.

## 3. 방법 (사전 확정)
**실행 순서(고정)**: ① 계절성 판정 → ② 비교 기준 선택(임시 감소 기준 30%, k=3) → ③ 창 길이 k 선택(임시 30%) → ④ 활동량 하한 Φ 산출(선택한 비교 기준·k) → ⑤ 판정 가능 집합 확정(r 정의 and C ≥ Φ) → ⑥ 변화율 분포와 n 산출 → ⑦ 최종 탐지. **주 k는 ③에서 P36으로 한 번 정해 고정**하고 P35만·P35+에는 그대로 적용한다(재현 확인은 같은 k에서의 결정 비교로 보고). 모든 단계에서 입금은 쓰지 않는다.

1. **④-1 비교 기준**: 월 지수(그 달 기업 I1 중앙값 ÷ 그 해 월 중앙값 평균)로 계절성을 판정한다. *연도 쌍 상관 평균 ≥ 0.5* 이고 *연도별 최대/최소 평균 ≥ 1.3* 이면 '있음'. 있으면 직전 기간 vs 작년 같은 달 중 **월별 탐지율 최대/최소가 작은 방식**, 없으면 직전 기간. 두 방식은 **같은 후보월 범위 [k+12, 30]** 을 쓰고, 기준값 C·활동량 하한·판정 가능 집합은 **방식별로 따로 계산**한다.
2. **④-2 창 길이 k** ∈ {1, 2, 3, 6}: **일시적 하락** = 탐지월 t의 **사후 k개월 변화율 r_post(i,t) ≥ −10%** (아래 4b, 비교 방식과 무관하게 전년 동기 대비). 일시적 하락 비율이 **20% 미만인 가장 짧은 창**. 모두 20% 이상이면 인접 창 두 비율 z검정으로 더 이상 줄지 않는 창. (이전의 '다음 한 달 ≥ 비교 평균 90%'는 k=1과 k=6에서 다른 뜻이라 바꿨다. **다음 한 달 반등**은 그 달의 전년 동월 대비로 계산해 별도 보조 지표로만 보고한다. 사후 구간이 관측되지 않으면 분모에서 빼고 비율을 보고.)
3. **④-3 활동량 하한**: 아래 4b의 수식.
4. **④-4 판정 기간**: 후보월 t ∈ [k+12, 30] (사후 6개월 추적 필요). **최대 후보월 수 = 19 − k** (두 비교 방식 동일: k=1: 18, 3: 16, 6: 13). 실제 판정 가능 기업-월 수는 결측·하한 때문에 더 적으므로 **방식별로 따로 보고**한다.
5. **④-5 변화율 분포와 n**: 판정 기간·하한 이상 기업-월의 기술통계(관측 수, 평균, 표준편차, 1·5·10·25·50·75·90 백분위수, 왜도). 평균보다 분위수 중심. **n₀ = −100 × Q₀.₀₅(r)** (r의 5번째 백분위수, 선형 보간, **양의 % 값**), **n = max(5, n₀를 5%p 단위로 반올림(0.5 올림))**. n₀ ≤ 0 이면 탐지 임계를 정의할 수 없으므로 중단하고 분포를 보고한다. 정확히 r = −n/100 인 기업-월 비율을 보고하고 1%를 넘으면 n ± 5%p 경계 민감도를 함께 낸다.

## 4. 표본, 빈 달, 판정 불가
- **결정은 P36에서** 내린다. **P35만**(P36과 겹치지 않는 기업)에서 같은 결정이 나오는지 재현하고, P35+는 포함 범위 민감도로만 보고한다 (다르면 둘 다 보고).
- **M0 쌍 맞춤**: *두 시점 모두 관측된 달만* 짝지어 평균한다 (`cntlib.paired_means`). **최소 짝 수 = max(k − 1, 1)** (`cntlib.min_pairs`) — k=1이어도 최소 1쌍이 있어야 하며, 미달이면 **'판정 불가'**. 짝의 정의는 비교 방식마다 다르다(4b).
- **M1 인과적 채움 (민감도)**: 탐지 이력을 **후보월 s마다 순차적으로 재계산**한다. 후보월 s에서는 **월 ≤ s의 관측값만** 써서 과거 빈 달을 채우고(`cntlib.fill_causal`), s 이후 값은 쓰지 않는다. 후보월 s 자체가 미관측이면 '판정 불가'. **후보월 s의 채움값과 판정은 그 시점에 고정되며 이후에 얻은 관측으로 소급 갱신하지 않는다.**
- **'거래 0'과 '미관측'을 구분**한다 (0은 기록된 값, 미관측은 결측).
- **판정 불가 3종을 정상으로 세지 않고 따로 집계**한다: (a) 비교 기간 평균 0, (b) 활동량 하한 미만, (c) 빈 달 부족. 판정 불가율을 **월·업종군·규모·탐지 전 건수 수준별**로 보고한다 (공백이 위축과 관련되면 판정 가능 집단의 위험이 달라지므로). P1에서 2024.03과 2025.12에 빈 달이 평소보다 많았다.
- **적용 범위**: 활동량 하한은 저활동 기업을 판정 대상에서 제외한다. 이 단계에서 **제외 비율과 제외 기업의 사전 특성**(업종군·비교 기간 I1 수준·천장 보유 여부)을 보고하고, **결론은 '하한 이상 기업'에 한정**한다. 제외 기업의 향후 입금 결과는 P5의 참고표로 보고한다(P4에서는 입금을 쓰지 않는다).
- **사후 고정 규칙**: n·Φ·k·θ는 36개월 P36 자료 전체로 정한 **사후 고정 규칙**이다. 이 분석이 보는 것은 실시간 운영 성능이 아니라 '이 기간의 후행 연관'이다. M1의 인과적 채움은 후보월의 **자료 가용성**만 재현하며 문턱 산출 자체는 실시간이 아니다.

## 4b. 사전 고정 규칙 — 실행 가능한 수식 (입금 결과를 열람하기 전에 고정)
기업 i, 후보월 t(1~36), I1[i, m] = m월 국내 5채널 근사 건수 합, 창 길이 k, 비교 간격 L (**전년 비교 L = 12, 직전 기간 비교 L = k**).

| 항목 | 규칙 |
|---|---|
| 짝지은 달 | S(i,t) = { m ∈ [t−k+1, t] : I1[i,m] 과 I1[i,m−L] 이 모두 관측 }. 최소 짝 수 `max(k−1, 1)` (방식별로 따로 계산) |
| 변화율 | r(i,t) = (R − C) ÷ C, R = mean_{m∈S} I1[i,m], C = mean_{m∈S} I1[i,m−L]. **C > 0** 이고 최소 짝 수 충족일 때만 정의 |
| 사후 변화율 | r_post(i,t) = 창 [t+1, t+k] 를 **비교 방식과 무관하게 작년 같은 달(L=12)** 과 비교한 변화율(짝 규칙·최소 짝 수는 r 과 같음). **일시적 하락 = r_post ≥ −10%** (t+k ≤ 36 인 후보월 t ≤ 30 에서 정의). 직전 기간 비교에 L=k 를 쓰면 회복이 아니라 '탐지 창 대비 추가 하락 여부'를 재게 되므로 사후 구간은 항상 전년 동기와 비교한다 |
| 활동량 하한 Φ | 판정 기간에서 r이 정의된 (i,t) 중 **C > 0** 인 것만 대상. C를 10분위(값 기준 경계)로 나누되 **경계가 같으면 합치고, 분위당 100 기업-월 미만이면 인접 분위와 병합**. 분위별 IQR(r)을 구하고 ref = 상위 5개 분위(병합 시 상위 절반) IQR의 중앙값. **모든 d ≥ d\* 에서 IQR_d ≤ 1.5 × ref** 인 가장 낮은 d\* 의 하한값이 Φ (d\*=1이면 Φ=0). **P36에서 한 번 정해 고정**하고 P35만·P35+ 에 그대로 적용. 기업 단위 재표집 200회에서 Φ의 분포(중앙값·범위)를 **보고**(Φ는 바꾸지 않음) |
| 판정 가능 | r이 정의되고 C ≥ Φ |
| 탐지 | 판정 기간 [k+12, 30]에서 r(i,t) ≤ −n/100 이 **처음** 성립하는 달 (기업당 1건, 허용 오차 1e-9). n은 ④-5에서 정한 **양의 값** |
| 입금 약화 O1 | g(i,t) = (mean_{m=t+1..t+6} 입금 − mean_{m=t−11..t−6} 입금) ÷ mean_{m=t−11..t−6} 입금. 같은 달 짝지은 달만 사용(최소 5쌍), 분모 0이면 O1 판정 불가(제외하고 비율 보고). **θ_O1 = P36, t ∈ [k+12, 30], 판정 가능 (i,t) 전체(탐지군 여부와 무관)의 g의 5번째 백분위수**(고정), 약화 = g ≤ θ_O1 |
| 탐지 전 입금 추세 h_pre (보조 '입금 정상'·균형표·직접 조정 S1) | **탐지 창 [t−k+1, t]와 겹치지 않는 구간**만 쓴다(k=6이면 [t−5,t]는 이미 건수가 줄던 시기). 일반식: h_pre(i,t) = [mean_{m=t−k−5..t−k} 입금 − mean_{m=t−k−17..t−k−12} 입금] ÷ mean_{m=t−k−17..t−k−12} 입금 (쌍 맞춤, 최소 5쌍 → **t ≥ k+18 에서만 정의**, k=6이면 t ≥ 24). 정상 = h_pre > θ_h, θ_h = P36, t ∈ [k+18, 30], 판정 가능 (i,t) 전체 h_pre의 5번째 백분위수(고정). **P5 Codex 4차 반영으로 이전 정의(t−5..t)를 수정**(입금 열람 전) |
| 규모 5분위 | 경계 = P36 판정 가능 (i,t)의 C의 20·40·60·80 백분위수(고정). **탐지 창보다 앞선 비교 기간의 값**이라 탐지 신호·결과와 얽히지 않는다 |
| 업종군 | 업종 대분류 중 P36 기업 수 상위 5개 + 기타 (고정) |
| 층 | 기준월 t × 규모 5분위 × 업종군. 탐지군 층별 기업 수로 **직접 표준화**. 대조군이 5개 미만인 층은 업종군을 합쳐 재계산하고, 그래도 부족하면 해당 탐지군을 비교에서 **제외하고 제외율을 보고** |

## 4c. 대안 지표 (P7에서 비교, 주 지표는 I1 변화율)
- **P2 결과로 확정된 필수 병행**: 인터넷 천장 30.9%, cap 민감도 99분위 96%(기준 25% 초과)이므로 I2 병행은 필수이고, **탐지군·결과표를 '인터넷 천장 보유(코드 9) 여부'로 나눠 보고**한다. 천장 보유 기업은 I1이 사실상 천장 채널 한 개(중앙값 87.5% 영향)에 좌우되고 천장에 머무는 동안 건수가 줄어도 변화가 보이지 않는다.
- ΔI1 **절대 감소량**(건), **ΔI2 순서 코드 합의 하락 단계 수**(순서만 이용하므로 50건초과 상한 가정에서 자유로움 — **주요 강건성 결과로 취급**), ΔI3 사용 채널 수 감소, I1_low / I1_high(상한 시나리오).
- 비교 항목: 탐지군 겹침(Jaccard), H-C1 방향. 소규모 기업에서 한 구간 이동이 극단적 비율을 만드는 문제를 이 지표들로 점검한다.

## 4d. 첫 산출물: k별 판정 가능 월과 사건 수, 검정력 점검
36개월 자료에서는 탐지(k+12 이후)와 사후 6개월 검증을 모두 요구하므로 탐지 가능 월이 짧다. 노트북의 **첫 표**로 k별·비교 방식별 (최대 후보월 수, 판정 가능 기업-월 수, 판정 불가 3종 비율, 임시 감소 기준 30%와 최종 n에서의 탐지 기업 수 N1, 대조군 규모 N0)를 낸다.
- **검정력 근사(데이터 없이 정의로 계산)**: O1은 정의상 판정 가능 전체의 하위 5%이므로 대조군 약화율 p0 ≈ 5%로 둔다. 탐지군 약화율 p1 = RR × p0, 로그 비율비의 표준오차 SE² ≈ [(1−p1)/(N1·p1) + (1−p0)/(N0·p0)] × **설계 효과 1.5**(기업 내 중복·위험집합 중복 가정). **최소 검출 비율비 MDE** = 80% 검정력·양측 5%에서 ln(RR) ≥ 2.8 × SE 가 되는 가장 작은 RR. 노트북은 RR = 1.5, 2, 3에서 기대 약화 사건 수(N1 × p1)와 기대 95% CI 폭, 그리고 MDE를 보고한다.
- **확증 보고 조건(운영 기준, 통계적 보장이 아님)**: **N1 ≥ 100 이고 MDE ≤ 3.0** 이면 H-C1을 확증으로 보고하고, 아니면 **탐색적으로만** 보고한다. 설계 효과와 문턱은 가정이며 실제 CI 폭은 P5의 군집 부트스트랩으로 확인한다.

## 4e. 수정 규칙 v2 (노트북 04 첫 실행 후, **입금 열람 전**에 I1 분포만 보고 한 수정)
**배경**: 등록 규칙(v1)대로 실행하자 활동량 하한 Φ가 I1의 cap 값(60) 근처에서 정해졌고, 판정 가능 기업의 97%가 천장(50건초과 채널) 보유 기업이었으며, 변화율 IQR이 C 60 위에서 0.04~0.07로 급락했다. 진단(§10)으로 확인: 천장 채널이 있는 칸은 I1이 cap 값으로 기계적으로 고정되어 IQR이 인공적으로 작고(천장 없는 칸은 C 상위 구간에서도 IQR 0.20), 등록 규칙 탐지의 65%는 천장 채널이 하락의 50% 이상을 설명하며 탐지월 변화율 중앙값은 임계 바로 아래(−17~−19%)였다. 같은 규칙에서 cap(51·60·100)만 바꿔도 탐지 집합의 겹침이 0.48~0.53이었다. **규칙 구현 오류가 아니라 규칙과 cap 인공물의 상호작용**(상위 분위 IQR을 기준으로 삼는 규칙이 포화된 지수에서 기준을 끌어내림).

**v2 = v1과 같되 (원래 등록안이 아니라 '결과(입금) 확인 전 개정안'), 활동량 하한 Φ를 정할 때 분위별 IQR을 '최근 창과 비교 창에 50건초과 채널이 없는 칸'에서만 구한다.**
- 정해진 Φ는 모든 칸(천장 칸 포함)에 적용하고, n은 판정 가능 칸 전체의 5번째 백분위수(양의 %, 5%p 반올림, 최소 5)로 v1과 같다. ①~③(계절성·비교 기준·k)은 Φ와 무관하므로 그대로다.
- 천장 칸의 구분은 **두 창 어디에든** 코드 9가 있는 것으로 대칭이라 (현재 창만 보면 '아직 천장에 있는 칸'이 빠져 방향성이 생김) 한쪽 방향의 선택 편향을 만들지 않는다.
- **v1은 민감도로 남기고(P7), P5의 주 결과는 v2**를 쓴다. 천장 보유 층·규모 층별 결과는 두 버전 모두 따로 보고한다.
- 이 수정은 **결과(입금)를 보기 전**, I1 분포의 진단만으로 한 것이다. 변경 이력에 '결과를 본 뒤 변경: 예(입금 열람 전)'로 남긴다.
- **남는 한계**: n을 판정 가능 칸 전체에서 풀링해 정하므로 활동량이 작아 변화율이 흔들리는 기업이 천장 보유 기업보다 더 자주 탐지된다. P5의 층(기준월×규모 5분위×업종군) 비교와 규모·천장 유무별 결과 보고로 대응한다.

## 5. 위험과 대응
- **천장**: I1은 큰 기업에서 cap 가정에 민감하다(P2 실측: 천장 보유 기업-월의 I1 중 50건초과 몫이 상위 10%에서 98%) → P7의 상한 시나리오·ΔI2로 확인하고, 천장 보유 여부별로 나눠 보고. 해석(가설): 가장 큰 고객의 위축이 가장 늦게 잡혀 탐지율이 규모에 따라 달라질 수 있다.
- **이산성·0 근처**: 소규모 기업은 I1이 작아 변화율이 크게 흔들린다 → 활동량 하한과 대안 지표로 대응.
- **계절성**: 건수는 입금과 계절 패턴이 다를 수 있다 → 판정 규칙을 그대로 적용하고 결과를 보고.
- **채널 이동**: P3 결과 대규모 이동 증거가 없고(주 채널 유지 약 95%, 확증 쌍 미지지) 채널이 함께 줄어드는 경향이 우연보다 뚜렷해 I1 하나로 진행한다. 이동으로 인한 오탐은 P6에서 탐색적으로만 확인.
- **k 선택 규칙의 한계**: 모두 20% 이상일 때 쓰는 '인접 창 비율 검정'은 표본이 작으면 검정력이 낮아 짧은 k가 선택되기 쉽다. 노트북이 k별 일시적 하락 비율을 모두 보여 주므로 선택이 20% 경계 근처이거나 검정력 부족 때문인지 판정 기록에 적고, 필요하면 P7에서 인접 k를 민감도로 본다.
- **단월 잡음**: P3 결과 월 단위 기업 내 변동은 채널 간 거의 독립이다(고유값 ≈ 1). 한 달 판정(k=1)은 잡음에 취약하므로 창 평균(k)과 채널 합산이 필수이고 4d의 k별 사건 수로 확인한다.
- 이 단계의 임시 감소 기준(30%)은 P5에서 n이 확정되면 **P7에서 최종 n으로 재확인**한다.

**해석(가설)**
- v2의 탐지는 **깊은 감소**(중앙값 −42%)이고 천장 인공물에 덜 좌우되어(천장 설명 21%) 위축으로서의 의미가 v1보다 훨씬 분명하다. cap 가정에 대한 의존도 크게 줄었다.
- **탐지율이 규모에 따라 12배 차이(46% → 4%)**: 작은 법인은 건수가 몇 건만 바뀌어도 구간이 달라지고 사업 부침(휴업·폐업)도 크다. 큰 법인은 거래처·직원 기반이 커서 월 건수가 안정적이고 천장 때문에 건수 구간으로는 위축이 가장 약하게 측정된다. 따라서 v2의 탐지군은 **중소 규모 법인 중심**이며, 큰 고객의 위축에 대한 증거는 약하다(상위 5분위 탐지 26곳 안팎).
- **P35만은 같은 규칙에서 더 자주 탐지(27% vs 19%)** — P2에서 본 대로 활동이 적고 변동이 큰 집단과 일치한다. 같은 규칙의 적용과 별개로 두 집단은 **다른 모집단**이다.
- v2도 풀링한 n 때문에 변동이 큰 작은 기업이 더 자주 탐지된다. P5는 **규모 층 안에서 비교**해야 하고, 규모 5분위·천장 유무별 결과를 반드시 따로 보고한다.

**P4 판정 (2026-10-01)**: 규칙을 **v2**로 확정한다. 비교 기준 = 직전 기간, 창 길이 k = 6개월, 활동량 하한 Φ = 11.17, 탐지 임계 n = 35%. v1은 민감도(P7). 결론의 적용 범위는 **하한 이상 기업(P36의 74.5%)** 이며 중소 규모 법인에 편중된다. 노트북 04의 Codex 코드·설계 검증(체크리스트 4c)이 남았다.
