# 분석 계획 — 어느 단계에서 어떤 변수를, 어떤 방법으로

> **⚠ 2026-09-29 기준 옛 정의 문서.** 이 문서의 중심 질문(회복 vs 지속저조)과 수치(2,700 / 2,959 / 338 / 5,659)는
> 폐기된 정의(감소 30%, 법인 첫 신호, 회복 판정)의 것입니다. 현재 분석과 수치는 `../최종/분석보고서_최종ver.html`,
> 계산 기준은 `../최종/감소신호_판정기준_최종ver.html` 을 따릅니다. 변수정의서의 '사용단계' 번호 뜻을 확인하는 용도로만 남깁니다.

> 같이 볼 것 — [변수정의서.md](변수정의서.md) (변수 41개 정의), [전처리_가이드.md](전처리_가이드.md)

## 목적

| 항목 | 내용 |
|---|---|
| 중심 질문 | **회복(2,700) vs 지속저조(2,959)를 가르는 요인은 무엇인가** |
| 표본 | n = 5,659 (이탈 338 제외) |
| 종속변수 | `recovered` — 회복 1 / 지속저조 0 |
| 최종 산출물 | 개입이 필요한 고객을 선별하고, 유형별로 상품을 연결한다 |

**표본 크기는 제약이 아니다.** 5,659개면 변수 41개를 다 넣어도 통계적으로 문제없다.
진짜 제약은 **서로 겹치는 변수가 많아 해석이 안 되는 것**이다. 그래서 단계별로 줄여 쓴다.

---

## 0단계 — 분류가 믿을 만한지 먼저 확인

**1단계를 시작하기 전에 해야 한다.** 종속변수가 오염돼 있으면 뒤의 모든 결과가 무의미하다.

### 확인 ① 지속저조 2,959개의 구성

| 경로 | 내용 | 진짜 저조인가 |
|---|---|---|
| ① | 판정 창에 미관측 달이 있어 **회복 판정 자체가 불가** | 아님 |
| ② | 장기 미관측 후 **정상 복귀** (갭 전후 거래 수준 1.000) | 아님 |
| ③ | **계절·수주형** 법인의 타이밍 차이 (`거래집중도` 상위) | 아님 |
| ④ | 관측이 유지됐고 실제로 회복 기준 미달 | **맞음** |

①②③의 합이 크면 분류를 다시 짜야 한다. 작으면 각주로 처리하고 진행한다.

### 확인 ② 이탈 정의의 근거

현재 정의 "3개월 이상 미관측 + 끝까지 복귀 없음"에는 데이터 근거가 없다.
"3개월"은 관례로 정한 값이고, "복귀 없음"은 관측이 202512 에서 끝나 못 본 것일 수 있다.

- 관측 기간 **안쪽에서 끝난 갭만** 모아 **갭 길이별 복귀율**을 구한다 (3·4·6·9개월)
- 복귀율이 5% 밑으로 떨어지는 길이를 임계값의 근거로 삼는다
- 복귀율이 높으면 이탈 판정을 포기하고 회복/지속저조 2분류로 간다

### 확인 ③ 갭 처리 방식 민감도

`exclude`(현재) / `relax`(있는 달만으로 평균) 두 방식으로 돌려
회복·지속저조 비율이 크게 바뀌는지 본다. 크게 바뀌면 보고서에 명시한다.

> 이 셋은 `code/eda_gap_sensitivity.py`(8단계)의 과제다.

## 1단계 — 스크리닝 (두 집단 비교)

| 항목 | 내용 |
|---|---|
| 질문 | 회복군과 지속저조군은 무엇이 다른가 |
| 변수 | **35개 전부** (설명변수 전체). 이 단계는 걸러내는 것이 목적 |
| 방법 | 연속형 — 중앙값·사분위 + **Mann-Whitney U**<br>범주형 — 교차표 + **카이제곱** |
| 판단 기준 | **표준화 차이(standardized difference) 0.2 이상** |
| 산출물 | **변수별 효과크기 순위표** |

### ⚠ p값으로 변수를 고르면 안 된다

n 이 5,659 이라 실질적으로 의미 없는 차이도 전부 유의하게 나온다.
**효과 크기로 정렬하고, 상위만 2단계로 넘긴다.**

정규성을 가정하는 t-검정을 쓰지 않는 이유는 금액의 왜도가 극심해서다.
평균을 쓰면 결론이 뒤집힌 사례가 이미 있다(5단계 규모 층화).

### 이 단계에서만 쓰는 진단 변수

`활동개월수` · `거래집중도` · `감소_z` · `관측개월수` — 예측용이 아니라
**"이 집단이 오염됐나"를 확인하는 변수**다. 3단계 모델에는 넣지 않는다.

## 2단계 — 교란 통제 (분석의 핵심)

| 항목 | 내용 |
|---|---|
| 질문 | "채널이 많으면 회복한다"가 사실인가, **큰 회사라서** 그런가 |
| 변수 | 1단계 통과 변수 + 통제변수 `거래규모분위`, `갭보유` |
| 방법 | **층화 분석** (규모 5분위 안에서 채널수별 회복률) |
| 보조 | 로지스틱 회귀로 오즈비 확인 |

### 층화를 먼저 쓰는 이유

**표로 보여줄 수 있다.** "규모가 같은 회사끼리 비교해도 채널 많은 쪽이 회복률이 높다"는
표 한 장이 회귀계수보다 설득력이 있다.

### 반드시 통제할 것

- `거래규모분위` — 채널 수 효과(29.5% → 58.5%)가 규모의 대리지표일 수 있다
- `갭보유` — 안 넣으면 "소규모는 회복 못 한다"는 착시가 나온다

### 업종 비교는 분위로

고정 임계값(±20%)으로 3분할하면 **신호 집단은 정의상 전부 30%+ 감소이므로
100%가 "업종보다 많이 감소"로 찍힌다.** 반드시 `업종내_상대감소`(분위)를 쓴다.

### 외부 데이터는 여기서만 쓴다

`기준금리` · `업종생산지수` 등은 **업종 × 월 단위**라 같은 셀 법인이 전부 같은 값이다.
개별 회사를 가르는 힘이 없으므로 **시기 통제**와 **상호작용**으로만 쓴다.

```
업황 악화 × 여신 보유 × 현금버퍼 부족  ->  회복 불가 조합
```

## 3단계 — 회복 확률 모델

| 항목 | 내용 |
|---|---|
| 질문 | 이 회사가 회복할 확률은 얼마인가 |
| 변수 | **8~12개로 줄여서** (핵심 8개에서 시작) |
| 방법 | **로지스틱 회귀** — 계수 해석이 필요하므로 |
| 보조 | 트리 계열은 성능 비교용으로만 |
| 평가 | AUC + **상위 10% 리프트** |
| 검증 | **시간 분할** — 학습 t <= 202411 / 검증 t >= 202412 |

### 변수 줄이는 규칙

- 상관 **0.7 이상**인 쌍은 하나만 남긴다
- **VIF 5 초과**면 제거
- `before_금액`·`after_금액`은 `감소율`의 구성요소이므로 같이 넣지 않는다

### 시간 분할로 검증하는 이유

랜덤 분할은 성능이 과대평가된다. 실무에서는 과거로 배워 미래를 예측하므로
**t 를 기준으로 앞 기간 학습 / 뒤 기간 검증**이 정직하다.

### 상위 10% 리프트를 같이 보는 이유

영업 자원은 한정돼 있다. **전체 정확도보다 "상위 10%를 찍었을 때 실제로 몇 %가
지속저조인가"** 가 실무 가치를 나타낸다.

## 4단계 — 유형화 → 상품 연결

| 항목 | 내용 |
|---|---|
| 대상 | **지속저조 2,959개만** (0단계에서 정제한 집단) |
| 방법 | **규칙 기반 분류** — k-means 보다 우선 |
| 변수 | 자금 3~4개 + 관계 1~2개 |

```
현금버퍼 < 1개월              ->  운전자금 대출
이용채널수 = 1                ->  채널 확대 유도 (자동이체·카드·인터넷뱅킹)
요구불_비중 하락 + 총액 하락    ->  금리 경쟁력 있는 예금
여신 보유 + 레버리지 높음       ->  대출 조건 재조정
```

### 규칙 기반을 먼저 쓰는 이유

k-means 는 군집에 이름을 붙여야 하고, 영업에 설명하기 어렵다.
**규칙은 조건이 그대로 실행 지침**이 된다.
k-means 는 규칙으로 안 갈리는 잔여 집단을 볼 때 보조로 쓴다.
(쓸 경우 변수 표준화 필수, k 는 실루엣 계수로 선택)

### 겹치는 묶음 — 상관 보고 하나만

| 묶음 | 우선 선택 |
|---|---|
| `거래_변동성` / `감소_z` / `거래집중도` | `거래_변동성` (나머지는 진단용) |

| `보유상품수` / `이용채널수` | `이용채널수` |
| `갭보유` / `관측개월수` | `갭보유` |

### 후순위 — 1단계 효과크기를 보고 결정

`시도` · `등급` · `전담여부` · `채널수_변화` · `여신_증감` · `출금입금비` · `감소_기울기` · `거래기간`

미리 버리지 않는다. 1단계에서 효과크기가 크게 나오면 살린다.

## 하지 말아야 할 것

| 하면 안 되는 것 | 이유 |
|---|---|
| p값으로 변수 선택 | n=5,659 라 전부 유의하게 나옴. 효과크기로 고른다 |
| 평균으로 금액 비교 | 왜도가 극심. 중앙값·분위를 쓴다 |
| 랜덤 분할 검증 | 성능 과대평가. 시간 분할을 쓴다 |
| 겹치는 변수 동시 투입 | 계수 부호가 뒤집혀 해석 불가 |
| 외부 데이터를 단독 예측변수로 | 업종×월 단위라 개체 변별력 없음 |
| 업종 비교를 고정 임계값으로 | 신호 집단은 전부 30%+ 감소라 상수가 됨 |
| 0단계 건너뛰고 1단계 시작 | 종속변수가 오염돼 있으면 전부 무의미 |
