# Case 1 / Case 2 위축 신호 정의

## 1. 분석 기준

### 주 분석: Case 1

1. 전년 `T-14 ~ T-12`와 현재 `T-2 ~ T`의 `요구불입금금액`을 비교한다.
2. 각 구간의 대표 거래수준은 중앙값으로 정의한다.
3. 기준시점 `T`와 전년 기준시점 `T-12`는 반드시 실제 관측값이어야 한다.
4. 각 3개월 창은 최소 2개월 이상 실제 관측된 경우에만 대표값을 계산한다.
5. 3개월 모두 관측된 경우 3개 값의 중앙값을 사용하고,
   2개월만 관측된 경우 실제 관측된 2개 값의 중앙값을 사용한다.
   1개월 이하만 관측된 경우 해당 신호시점은 계산하지 않는다.
6. 전년 대표수준 대비 현재 대표수준이 30% 이상 감소한 경우 위축 신호로 정의한다.
7. 결측값을 인위적으로 생성하여 주 분석에 사용하지 않는다.

### 민감도 분석: Case 2

- 전년창 3/3 + 현재창 3/3 완전관측만 사용하여 동일 분석한다.
- 위축 임계값 `20% / 30% / 40%`를 비교한다.
- 내부 1개월 결측에 한해 선형보간을 추가 검증안으로 고려한다.
- `T` 또는 `T-12`를 과거값만으로 외삽하여 생성하지 않는다.

> 같은 법인의 반복 위축신호는 현재 단계에서 제거하지 않았다.

---

## 2. 기준 설명

### 왜 3개월 창을 사용하는가
단일 월의 일시적인 거래 변동에만 의존하지 않고,
전년 시점과 현재 시점의 대표적인 거래수준을 비교하기 위해 3개월 창을 사용한다.

### 왜 중앙값을 사용하는가
월별 요구불입금금액의 일시적인 급증·급감에 덜 민감한 대표값을 사용하기 위해 중앙값을 사용한다.

### Case 1의 2/3 관측 기준
주 분석에서는 결측이 1개월 존재하더라도 나머지 2개월이 실제 관측된 경우
해당 관측값만으로 대표값을 계산하여 표본 손실을 줄인다.

단, 기준시점 자체의 의미를 유지하기 위해 `T`와 `T-12`는 반드시 실제 관측되어야 한다.

### Case 2의 목적
Case 2는 두 3개월 창이 모두 완전관측된 법인만 사용하여,
Case 1의 2/3 관측 허용이 결과에 미치는 영향을 확인하는 민감도 분석이다.

### 위축률
위축률은 다음과 같이 정의한다.

```text
위축률 = (전년 대표수준 - 현재 대표수준) / 전년 대표수준
```

전년 대표수준이 0인 경우 분모가 0이 되므로 위축률 계산 대상에서 제외한다.

### 임계값 민감도 분석
30%를 주 기준으로 사용하되,
20% / 30% / 40%에서 위축신호의 규모와 패턴이 어떻게 달라지는지 비교한다.
