1. 4-1단계: 전체 3년을 합쳐 월별 패턴 확인

법인마다 원래 거래규모가 너무 다르니까 그대로 비교하지 않고
각 법인의 해당 월 입금 수준 - 그 법인의 전체 관측기간 평균 수준을 계산

**이 법인이 자기 평소보다 이 달에 얼마나 높거나 낮았나**로 바꾼 다음, 2023~2025의 같은 월을 전부 합쳐서 1월~12월별 중앙값과 평균을 계산.
log1p를 쓴 이유는 큰 금액 몇 개가 결과를 과도하게 끌고 가는 것을 줄이기 위해, 마지막에 다시 퍼센트로 변환해서 읽기 쉽게 함.

<코드>

# 4-1단계: 요구불입금금액의 월별 계절성 확인
# 법인별 거래규모 차이를 제거한 뒤, 월별 상대적 수준을 확인

season_check = clean_panel[
    ["법인ID", "기준년월", "업종_대분류", "요구불입금금액"]
].copy()

# 연도 / 월 생성
season_check["연도"] = (
    season_check["기준년월"] // 100
)

season_check["월"] = (
    season_check["기준년월"] % 100
)

# 금액 분포가 큰 편이므로 log1p 변환
season_check["log_입금"] = np.log1p(
    season_check["요구불입금금액"]
)

# 법인별 평소 거래수준 제거
season_check["법인평균_log입금"] = (
    season_check
    .groupby("법인ID")["log_입금"]
    .transform("mean")
)

season_check["평소대비_차이"] = (
    season_check["log_입금"]
    - season_check["법인평균_log입금"]
)

# 달별 대표적인 상대수준
monthly_season = (
    season_check
    .groupby("월")
    .agg(
        중앙값=("평소대비_차이", "median"),
        평균=("평소대비_차이", "mean"),
        관측수=("법인ID", "size")
    )
    .reset_index()
)

display(monthly_season)

monthly_season["중앙값_퍼센트해석"] = (
    np.exp(monthly_season["중앙값"]) - 1
) * 100

monthly_season["평균_퍼센트해석"] = (
    np.exp(monthly_season["평균"]) - 1
) * 100

display(monthly_season)

2. year_month_season: 같은 월이 해마다 반복되는지 확인

- 같은 월의 상대적 높고 낮음이 연도별로 재현되는가를 보기 위한 표.

<코드>

# 연도별로 같은 월 패턴이 반복되는지 확인

year_month_season = (
    season_check
    .groupby(["연도", "월"])
    .agg(
        중앙값=("평소대비_차이", "median")

    np.exp(year_month_season["중앙값"]) - 1

4. 4-2단계: 연도효과를 제거

<코드>

# 4-2단계: 연도 전체 수준을 제거한 뒤 월별 패턴 확인

> 2025년이 전체적으로 낮았다는 효과를 먼저 제거하고, 각 년도 안에서 1월·2월·3월이 서로 어떻게 다른지만 본다.

# 각 연도의 전체적인 수준 제거
season_check["연도기준_차이"] = (
    season_check["평소대비_차이"]
    - season_check
        .groupby("연도")["평소대비_차이"]
        .transform("median")
)

# 연도 × 월 중앙값
year_month_adjusted = (
    season_check
    .groupby(["연도", "월"])
    .agg(
        중앙값=("연도기준_차이", "median")
    )
    .reset_index()
)

# 퍼센트 해석
year_month_adjusted["퍼센트해석"] = (
    np.exp(year_month_adjusted["중앙값"]) - 1
) * 100

# 보기 좋게 피벗
adjusted_pivot = (
    year_month_adjusted
    .pivot(
        index="월",
        columns="연도",
        values="퍼센트해석"
    )
)

display(adjusted_pivot)

결론
- 법인별 거래규모 차이를 제거한 뒤 전체 3년을 합쳐 보면, 월별 요구불입금금액 수준에 차이가 존재한다. 
  특히 12월은 상대적으로 높고, 2월·8월·11월은 낮은 패턴이 나타났다.
- 하지만 연도별로 분리했을 때 모든 월에서 동일한 패턴이 반복되지는 않았다. 
  연도 간 월별 패턴 상관계수도 0.305 / 0.494 / 0.729로 차이가 있어, 12개월 전체에 걸쳐 강하고 안정적인 계절성이 존재한다고 보기는 어렵다.
- 특히 2025년은 대부분의 월이 음수로 나타났는데, 이는 단순 계절성뿐 아니라 2025년 자체의 전반적인 거래수준 하락 효과가 섞여 있었던 것으로 판단된다.
- 따라서 연도별 전체 수준을 제거한 뒤 다시 확인한 결과,
  - 12월: 3개 연도 모두 뚜렷한 양(+)의 효과
  - 2월: 3개 연도 모두 음(-)의 효과
  - 8월: 3개 연도 모두 음(-)의 효과
  - 10월: 3개 연도 모두 음(-)이지만 효과 크기는 작음
  - 그 외 월은 연도에 따라 부호가 바뀌어 반복성이 약함
- 즉, 요구불입금금액에 전 월에 공통적으로 적용되는 강한 계절성이 존재한다기보다는, 
  일부 특정 월에서 반복적인 계절효과가 나타나는 것으로 해석할 수 있는 상태인 것 같다.
